# anyone-can-push
Anyone can put anything here. Let's see what happens!

## Rules
Ok fine, not LITERALLY anything (I don't wanna get banned), so:
- No NSFW
- no CSAM
- No Malware
- No Viruses
- No Illegal Content*
- No Pirated Stuff
- No Deleting the Guestbook or other's guestbook entries
- No deleting other people's code
- No modifying the license
- No Insults
But everything else is allowed.

*Illegal Content = Content illegal under U.S. Jurisdiction
